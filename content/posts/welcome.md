## Welcome

This is the first post on **AI & Me** (dycoai).

This site runs on [Hugo](https://gohugo.io/) with the
[hugo-PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, and it is
deployed automatically to GitHub Pages via GitHub Actions.

As this site grows, posts will appear here. To add a new post, create a new file
under `content/posts/` and run `hugo server -D` to preview it locally.

Happy writing!

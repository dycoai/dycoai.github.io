When an AI agent must translate task instructions into executable logic, **Code & Script Generation** is the **agentic skill** that produces, refactors, and explains program code, scripts, queries, and code snippets.

It can be used to create new routines, modify existing implementations, generate database queries or command snippets, and clarify how code works, usually from natural-language requirements, existing code, or technical constraints.

Its value lies in accelerating software development, data processing, and automation tasks by converting specifications into syntactically structured and potentially runnable artifacts.

However, generated code still requires validation because it may contain logical errors, security weaknesses, inefficient designs, or assumptions that do not match the target system.

In human–AI work, this skill can either assist a professional programmer by drafting routine code or support non-programming professionals by producing small automation scripts, while final review, architecture decisions, and responsibility for correct operation typically remain with the human user.
